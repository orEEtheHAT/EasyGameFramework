# EasyGameFramework AR extension

Install EasyGameFramework at the same release first. Install this directory as a separate UPM package with the repository Git URL and `?path=Addons~/AR#v0.1.0`.

The manifest adds AR Foundation 6.3.0. The EasyBuilding adapter supplies AR placement integration. Select and configure the actual AR platform provider, session, tracking and permission handling in your project.

Read the EasyBuilding folder's README for its placement contract. This is an extension for a specific mechanism, not a universal AR game template. Validate on the intended physical device; the base framework's Windows tests do not cover AR tracking.
