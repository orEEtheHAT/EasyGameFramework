# EasyResources integration

Эта production-интеграция поставляется с EasyGameFramework и компилируется без импорта Samples. Не создавайте вторую копию её assembly в Assets.

Подключение и API: [EasyUI](../../../Modules/EasyUI/README.md). Соответствующий модуль владеет игровым состоянием; EasyUI управляет окнами, представлением и отдельными запросами ввода.
