# Отчёты

Файлы IntegrationWave1 и остальные ранее сохранённые JSON относятся к отдельному EasyResources. Их версии, пути, counts и измерения сохранены как исторические доказательства и baseline. Они не подтверждают Unity-работу новой staging-копии EasyGameFramework.

Актуальный этап: [Unification](../Unification.md). Статическая проверка исходников находится в `Audits/EasyResources/Unification`; после CUTOVER сюда добавляются новые результаты без переписывания исторических измерений.
