# Getting Started

**Framework example:** production Input integrations are already included; this sample adds only the demonstration/measurement code.

After importing, choose Tools > EasyGameFramework > Input > Create Getting Started Scene, then Play. The panel opens with sensitivity, per-binding rebinding, reset and in-memory Capture/Restore. Close with Escape/East; reopen with Tab/Start. Gameplay Interact defaults to E/Gamepad West. Mouse or right stick rotates the preview cube. Use a gamepad's D-pad and South to navigate/select panel rows.

This scene is an input preview, not an FPS controller. For your own ECM2 player, use Tools > EasyGameFramework > Input > Connect Selected Player; the EasyMovement demo sample is optional. Full installation and API examples are in the package README.
