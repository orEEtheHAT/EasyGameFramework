# FPS input example

Production input integration is already available in EasyGameFramework; no adapter import is needed. This sample only adds a demo scene builder.

Run Tools > EasyGameFramework > Input > Create EasyMovement Scene. The project-local scene is written under Assets/EasyGameFramework/Input. It uses the module's FP_Player_Sample/FP_MainCamera_Sample prefabs and the standard Input profile. Press Play, move with WASD/mouse and use Tab/Start for the standalone settings panel.

For your own scene, select the FPS player and use Tools > EasyGameFramework > Input > Connect Selected Player instead. ECM2 is a standard required dependency and its commercial source is not bundled here.
