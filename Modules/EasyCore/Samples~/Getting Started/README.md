# Core / Getting Started

Part of EasyGameFramework. Import this sample once from the framework's Package
Manager page. Choose **Tools > EasyGameFramework > Examples > Core > Create First Run**.
Enter Play Mode: the Inspector and Console show
`EasyCore first run: 8/8 checks passed.`

No input actions, camera, assets or Inspector fields need configuring.
The command adds an undoable GameObject to the current scene.
Alternatively add **EasyGameFramework > Examples > Core First Run** to an empty object.
The example does not change global timeScale or write files.

Read CoreFirstRun.cs for calls to all three mechanisms. The Editor helper is
excluded from Player. Only import one copy of the EasyCore.Samples assembly.
