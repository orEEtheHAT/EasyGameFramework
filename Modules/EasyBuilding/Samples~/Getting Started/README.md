# Building / Getting Started

Импортируйте этот пример и выполните Tools > EasyGameFramework > Building > Create Getting Started Scene. Пример генерируется из исходников для текущего URP проекта; устаревшей готовой сцены нет.

1 free; 2 free in zone без grid; 3 grid in zone; 4 sockets; 5 Resources payment. R/Q rotation, ЛКМ confirm, Esc/ПКМ cancel. Resources/Combat/Feedbacks доступны штатно и не копируются из Samples.

Подробные действия: Modules/EasyBuilding/Documentation~/DesignerFirstRun.md.
