# Типографика EasyUI

Для оформления существующей uGUI-подписи с TextMeshProUGUI добавьте **Styled Text** и выберите роль. Кнопка **Apply preview to label** показывает результат в Edit Mode и поддерживает Undo. Вызов `UIText.Add(gameObject, text)` создаёт обычный текст с ролью Body. Явный числовой размер сохраняет прежнее поведение. Для указания роли используйте `UIText.Add(gameObject, text, UITextRole.Body)`. Роль задаёт размер, цвет, начертание и оформление. Выравнивание, перенос строк, раскладка и назначенный шрифт остаются у самой подписи.

| Роль | Размер по умолчанию | Применение |
| --- | ---: | --- |
| Title | 32 | Заголовок окна |
| Speaker | 20 | Имя собеседника |
| Body | 22 | Реплика или запись в журнале |
| Button | 20 | Ответ или команда |
| Caption | 16 | Короткая второстепенная подпись |
| Marker | 18 | Метка поверх игрового мира |

Это единицы Canvas. Для базовой компоновки используйте Canvas Scaler → Scale With Screen Size, например с разрешением 1280×720. Для длинных текстов и увеличенного размера используйте переносы, layout и ScrollRect. Масштаб не изменяет размеры вручную заданных RectTransform.

**Тема.** Создайте **Create → EasyGameFramework → UI → Typography Theme** и назначьте ассет в **Window Manager → Typography**. Без назначения используется Standard. **Font** по-прежнему отвечает за гарнитуру. Можно переопределить тему одной подписи полем **Theme Override**. После программной правки полей SO вызовите `manager.RefreshTypography()`.

**Оформления.** Paper использует родной материал шрифта. Ink добавляет тёмный контур. Gilded сочетает золотой градиент роли Title с медленным бликом; цвет градиента задаётся в роли. Beacon добавляет мягкий ореол для меток. Letterpress рассчитан на TMP SDF-атласы. Пользовательский SDF-шрифт использует свой атлас; для bitmap-шрифта выбирается его родной материал. Для символов запасной гарнитуры включите Match Material Preset в TMP Settings, если хотите сохранить оформление и на них.

Для своего эффекта назначьте TMP-совместимый SDF материал прямо в роли (Custom Material). Custom Still Material задаёт неподвижную версию. Если он пуст, Reduced Motion использует родной материал гарнитуры.

**Параметры игрока.** `WindowManager.ReadingPreferences` принимает масштаб от 0.8 до 1.6, флаги reducedMotion и highContrast. Изменения сразу обновляют активные Styled Text. Reduced Motion выбирает неподвижный материал; High Contrast даёт белые буквы с тёмным контуром без градиента. Для EasySave можно зарегистрировать `UIReadingSave.Create(manager)` в Preferences. Выбор темы и игровые слоты остаются отдельными.

В FrameworkPlayground откройте Tab → Текст. Сравните реплику, имя и маркер, измените масштаб и проверьте его в разговоре с паромщиком. Пункты основного меню «Сохранить настройки» и «Загрузить настройки» включают предпочтения чтения.

**Проявление субтитров.** На подпись TextMeshProUGUI добавьте **Text Reveal**. Включите Play On Enable для готовой надписи либо передавайте новую строку через `reveal.Play("Новая реплика")`. Duration задаёт время всей волны в секундах независимо от длины текста; 0 — мгновенный показ. `Replay()` повторяет эффект, `Complete()` сразу открывает весь текст. Для пропуска мышью включите Click To Complete и Raycast Target на самой подписи. При использовании динамического текста вызывайте Play на каждую новую реплику. Reduced Motion и High Contrast у ближайшего Window Manager показывают её сразу.

Эффект использует время без учёта Time.timeScale и полную геометрию TMP, поэтому переносы строк заданы с первого кадра. Шейдер Letterpress проявляет символы в порядке чтения и даёт тёплый передний край; стандартный SDF временно использует общий материал Reveal Paper со своим атласом. Для других материалов и встроенных спрайтов остаётся плавное изменение вершинной прозрачности. Проверить можно в Playground через **Tab → Текст → Повторить субтитр**.
