# EGF-001: заданная поза предмета в руках

Реализация и приёмка завершены 2026-11-16. Модуль EasyInteraction.

- После отдельного изменения default новые Grab Action используют `GrabPoseMode.AuthoredPose = 1` с нулевыми `GrabAction.LocalPosition` и `LocalEulerAngles`. Явно сериализованный `PreservePickupPose = 0` сохраняет старое поведение и не перезаписывается; числовые значения enum сохранены. `PoseMode` выбирает режим. Inspector показывает только поля выбранного режима.
- Один frame для позиции/вращения: внешний HoldPoint > Actor.HandAnchor > View. Масштаб frame игнорируется, View добавляет существующую distance/inspection Z. Local position позиционирует root Rigidbody; explicit GripPoint заменяет только позиционируемую точку. Rotation всегда root, rotation GripPoint игнорируется. Preserve по-прежнему использует COM без GripPoint.
- Authored использует существующий Stabilized solver/inertia. Legacy RotationMode/HoldOffset сохранены, но не участвуют в Authored. Нет дополнительного сервиса, anchor mutation, временных GameObject, parenting, телепортаций или аллокаций для расчёта позы в FixedUpdate. Контакты могут блокировать достижение цели.
- Manual rotation умножается после authored rotation. Transfer продолжает сессию с manual/inspection/distance; regrab сбрасывает runtime offsets. Two-owner использует среднюю позицию и существующее отклонение hand axis; authored rotation первого (без manual) задаёт начальную ориентацию даже до физического достижения цели. После ухода одного остаётся authored frame второго. Новых IK/двуручных механик не добавлено.
- Проверены независимость от исходной мировой позы, COM/root и явный GripPoint, приоритет/масштаб anchors, индивидуальные настройки, manual/inspection/distance, regrab/transfer/multi-owner, collisions/inertia/release/throw, defaults/serialization и регрессии ввода.

## Границы

Столкновения и Break Distance могут мешать достижению позы. Authored Pose использует Stabilized response; сохранённый Rotation Mode снова применяется при возврате в Preserve. Явные anchors сохраняют прежний приоритет над distance/inspection positioning. Multi-owner остаётся одним общим Rigidbody/GripPoint с hand-axis rotation, без отдельных IK-поз рук. Авторские значения рекомендуется настраивать до захвата для предсказуемой начальной hand-axis базы.

Для этого изменения Player-сборка и полный прогон всего фреймворка не выполнялись. Версия не изменена, публикация не проводилась. Проект Road of Haze, его13 предметов и таблица предложений не изменялись; миграция игровых данных выполняется отдельно.

Практическая инструкция и перенос проектного HoldPoint adapter: [физическое удержание](../GrabComfort.md).

## Authored Pose по умолчанию

По отдельному решению пользователя новые Grab Action теперь создаются с `PoseMode = GrabPoseMode.AuthoredPose`, `LocalPosition = Vector3.zero`, `LocalEulerAngles = Vector3.zero`. Сохранены динамический Rigidbody, Hold Distance2, Inertia0.12 и Ignore Owner Collisions=true. Числовые значения enum не переставлены; явно сериализованный `PreservePickupPose = 0` не перезаписывается. Если поле режима ранее отсутствовало в данных, используется новый initializer. Нет мигратора, Reset или OnValidate, которые меняли бы выбранный режим.

После смены default целевой прогон **EasyInteraction PlayMode166/166 PASS** включает15 физических pose-сценариев (в том числе2 новых для свежего компонента с разными исходными поворотами),8 shared native-input случаев обоих режимов и обе калиброванные warm-GC проверки. Отдельный **EditMode8/8 PASS** проверяет default свежего компонента, восстановление явно сериализованного Preserve и существующие setup/Undo/Redo сценарии. Failed/skipped/inconclusive=0; ошибок компиляции нет. Редактор вернулся в остановленное состояние с завершённым TestRunner и чистым исходным Playground. Эти числа относятся к новой проверке default и не складываются с историческими прогонами выше.

GCscope прежний: положительный контроль обнаружен; затем128 прогретых шагов удержания/обслуживания collision exclusions без событий managed allocation в обоих режимах. Создание предметов и новых leases этим scope не покрыто. Полный suite фреймворка, Player-сборка и публикация не проводились в рамках этой смены default.

Сценарий общего FrameworkPlayground передан координатору: существующие authored предметы сохраняют свою позу, а новый Grab Item из меню без настройки получает Authored/нулевую позу. Проверка — поднять экземпляры с разными мировыми поворотами, отпустить E, довращать R+мышь, повторно взять и бросить G; root должен возвращаться к одной локальной ориентации, сохраняя контакты. Явно сохранённый Preserve должен остаться0. Общий sample/сцену и независимую проверку координирует организационный чат. [Рецепт своего grab-префаба](../../README.md#свой-grab-префаб).
