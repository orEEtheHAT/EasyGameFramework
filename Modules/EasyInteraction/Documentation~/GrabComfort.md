# Физическое удержание

Новые Grab Action используют **Rotation Mode → Stabilized** по умолчанию. Начальные значения: Hold Distance = 2, Hold Offset = (0, 0, 0), Inertia = 0.12 секунды. На FPS-игроке используйте существующий EasyMovement Interaction Motor с назначенным Character и Actor.PlayerRoot, указывающим на тело игрока. Дополнительный glue-код или специальный слой предметов не нужен.

```csharp
actor.HandAnchor = null; // camera fallback, если точка руки не нужна этой игре
grab.RotationMode = GrabRotation.Stabilized;
grab.HoldDistance = 2;
grab.HoldOffset = Vector3.zero;
grab.Inertia = .12f;
// grab.IgnoreOwnerCollisions уже true по умолчанию.
```

Ожидаемый результат: центр массы предмета стремится к точке в двух метрах перед View. После поворота взгляда предмет плавно догоняет целевую позу и прекращает вращаться. Стена продолжает останавливать Rigidbody; удержание не телепортирует предмет через препятствие. Сохраняются Rotate, Inspect, AdjustDistance, Throw, передача и несколько владельцев.

В EasyGameFramework повторный основной Interact (E по умолчанию) отпускает собственный Grab независимо от движения мыши и текущего наведения. Для своего input reader используйте `actor.PressPrimary(out action, toggleInsteadOfHold)`; штатный адаптер EasyInput уже использует эту команду. Явные команды меню остаются адресными. [Маршрутизация ввода и matching Release](GrabReleaseInput.md).

## Точка и смещение

Приоритет всегда прежний: **Grab.HoldPoint → Actor.HandAnchor → Actor.View**. Явная точка HoldPoint или HandAnchor полностью заменяет вычисление расстояния перед камерой, включая inspection distance и AdjustDistance. Чтобы использовать Hold Distance, очистите обе ссылки.

Hold Offset измеряется в метрах по локальным осям выбранной точки, без умножения на scale. Для View он прибавляется к `(0, 0, HoldDistance)`; нулевой offset означает центр перед камерой. Для явного anchor он прибавляется к позиции самого anchor. GripPoint задаёт точку на предмете, которая следует к месту удержания; без него используется центр массы. GripPoint должен принадлежать удерживаемому Rigidbody.

Stabilized сохраняет начальную ориентацию предмета относительно выбранной точки и затем следует её повороту. Free=0, KeepInitial=1 и FollowView=2 сохраняют числовые значения; Stabilized=3 добавлен в конец. Для свободного вращения выберите Free явно; default нового модуля — Stabilized. Free оставляет физическое вращение свободным, пока его явно не контролируют Rotate, Inspect или второй участник.

## Инерция и физика

Inertia — время сглаживания целевой позы, от 0 до 0.5 секунды. Ноль отключает это сглаживание; предмет всё равно остаётся динамическим и следует физической пружине. В Advanced доступны Maximum Position Lag (0.35 м) и Maximum Rotation Lag (35°). Они ограничивают отставание **целевой позы**, а не расстояние настоящего Rigidbody до цели: столкновения с миром и ограниченное ускорение могут задержать сам предмет сильнее. Break Distance по-прежнему освобождает слишком далёкий предмет.

Stabilized прикладывает силу в центре массы, компенсируя положение GripPoint, и постоянно гасит угловую скорость демпфированным моментом. Поворот рассчитывается кватернионами через кратчайшую дугу. Сглаживание зависит от фиксированного шага времени; пауза Time.timeScale не накапливает скрытый импульс. Личная пауза InteractionTicket для физического Grab по-прежнему не поддерживается.

## Столкновения владельца

Ignore Owner Collisions включён по умолчанию. Исключаются только пары твёрдых коллайдеров данного Rigidbody и его владельца в PlayerRoot. Учитываются дочерние compound-коллайдеры; дочерние независимые Rigidbody не считаются частью предмета. Trigger-пары не меняются и не задерживают восстановление. Коллайдеры мира, collision layers и detectCollisions не отключаются.

EasyMovementInteractionMotor реализует `IInteractionCollisionFilter.AcquireCollisionExclusion(Rigidbody) : IDisposable`. Grab использует его автоматически. Адаптер добавляет OR-фильтр ECM2 для held Rigidbody: sweeps, overlaps и pushing не видят предмет. Прежний callback сохраняется; существующие ECM2 IgnoreCollision sets не изменяются. Независимые leases освобождают только свой запрос.

При drop/throw/cancel внутри владельца исключение остаётся до прекращения твёрдого пересечения. Проверяется физическая поза Rigidbody, включая дочерние коллайдеры, а не только интерполированный Transform. Внутренняя служба cleanup продолжает эту узкую работу после отключения или удаления GrabAction; она не двигает предмет. Пока два живых активных объекта действительно пересекаются, отсрочка намеренно сохраняется. После расхождения, отключения GameObject/коллайдеров или уничтожения участников запрос очищается; pooling и повторный захват создают своё владение. Для необычной пары, где ни один коллайдер не поддерживает ComputePenetration, используется консервативное пересечение bounds.

Исходное значение Physics.GetIgnoreCollision сохраняется до первого запроса. Несколько Grab-владельцев разделяют счётчик владения парой. Прямые внешние вызовы Physics.IgnoreCollision во время удержания не имеют owner/token и не могут быть надёжно отделены от нашего состояния: не меняйте те же пары этим способом до завершения удержания/отсрочки. Аналогично, прямая замена ECM2 colliderFilterCallback во время удержания может заменить наш фильтр; при освобождении чужой новый callback не перезаписывается. Для согласованного дополнительного исключения ECM2 используйте возвращаемую motor lease и Dispose.

Иерархии коллайдеров обновляются перед очередным физическим шагом; готовые compound-объекты учитываются сразу при захвате. Создание предметов, первое выделение списков и новые leases могут выделять память. Отсутствие GC проверяется отдельно для прогретого FixedUpdate и обслуживания существующих пар с калиброванным положительным контролем.
